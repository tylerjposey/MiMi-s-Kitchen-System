---
name: MiMi’s Kitchen layout continuity
description: A project-specific constraint on later feature phases.
---

Keep the established desktop application shell, navigation, and overall visual language when adding features. Change only the relevant page unless a requirement makes a shared-layout change necessary.

**Why:** The owner has repeatedly asked that working functionality and unrelated visual layout be preserved between phases.

**How to apply:** Extend the relevant tab in place. Do not reinterpret a new feature phase as permission to rebuild or restyle the whole application.
